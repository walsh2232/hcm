# Sprints

Sprints provide cadence, planning, and retrospective. They are **not** a fixed
commitment mechanism — with the critical path gated on external documentation
(`GAP-001`), a fixed commitment would be fiction. See `ADR-0004`.

Files: `sprint-###-<name>.md` (plan) and `sprint-###-retro.md` (retrospective).
Templates: [`../templates/sprint-plan.md`](../templates/sprint-plan.md),
[`../templates/retrospective.md`](../templates/retrospective.md).
