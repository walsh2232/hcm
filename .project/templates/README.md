# Artifact Templates

One template per artifact this project produces. Copy, fill, delete the guidance
lines in `<>` brackets. Placeholders use `###` so they never collide with real
identifiers, and `-000` identifiers are reserved for examples.

| Template | Use for | Owner role |
| --- | --- | --- |
| [`story.md`](story.md) | A work item card body | BA / PO |
| [`spec.md`](spec.md) | A functional or technical specification | BA / SA |
| [`adr.md`](adr.md) | An architecture decision | SA |
| [`test-case.md`](test-case.md) | A test case | QA |
| [`sprint-plan.md`](sprint-plan.md) | A sprint plan | PO |
| [`retrospective.md`](retrospective.md) | A sprint retrospective | Whole team |
| [`runbook.md`](runbook.md) | An operational procedure | DOC |
| [`doc-intake.md`](doc-intake.md) | A documentation intake batch record | DOC |

If a template does not fit the artifact, change the template — do not quietly
freelance a one-off format.
