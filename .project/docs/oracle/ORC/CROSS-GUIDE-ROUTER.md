## Answer-grounding workflow

1. Classify the request as configuration, end-user process, security, integration, reporting, feature entitlement, or release behavior.
2. Pick the official source that owns the topic, then confirm guide ID/edition.
3. Retrieve the entire relevant section, not only one search chunk. Preserve exact Oracle names for tasks, roles, privileges, profile options, formulas, lookups, and scheduled processes.
4. A guide edition ID is not the tenant quarterly release. If the tenant release is unknown, say that currency is unvalidated.
5. Separate source facts from tenant-specific facts and hypotheses.
6. Cite an exact topic and Oracle printed/physical PDF page where available.
7. If official material is silent or conflicting, create a gap; do not silently substitute model knowledge.
