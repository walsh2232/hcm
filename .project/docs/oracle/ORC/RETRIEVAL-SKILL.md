# Oracle Recruiting retrieval skill

## Purpose
Answer Oracle Fusion Cloud Recruiting implementation and support questions from registered Oracle sources. This is a retrieval procedure, not a standalone installable AI skill.

## Source and release rules
1. Prefer current Oracle Help Center content checked against the target tenant's quarterly release.
2. Use registered Oracle books as edition-bound evidence and cite exact headings and page numbers.
3. Use support articles and community content only under the project's source-tier policy.
4. Do not present model knowledge or another implementation as Oracle behaviour.
5. A guide identifier such as G34431-12 identifies a document edition; it does not prove the tenant's quarterly release.

## Retrieval procedure
1. Identify the subject: career site, application flow, candidate selection process, requisition, questionnaire, interview, offer, candidate pool, source tracking, fast formula, security, data disposal, integration, or scheduled process.
2. Search the private local topic/full-text index where available. Search exact roles, privileges, profile options, formulas, lookups, tasks, and scheduled process names verbatim.
3. Open the full chapter or section around the strongest hit. A chunk is a retrieval unit, not a sufficient citation on its own.
4. Record both Oracle printed page and physical PDF page. Check the PDF visually for spanning tables, columns, screenshots, and diagrams.
5. Distinguish documented product behaviour from tenant configuration and from inference.
6. If the source is silent, reference a GAP item and mark any interim approach provisional under an ASM item. Do not invent navigation, field names, privileges, defaults, or prerequisites.

## Configuration answer structure
- Outcome: what the configuration should accomplish.
- Prerequisites and access: only those supported by the source.
- Procedure: sequenced steps using Oracle's exact names.
- Validation: observable result and where to inspect it.
- Caveats: source-supported pitfalls; label inferences explicitly.
- Source: document ID, exact topic, Oracle printed page, physical PDF page, and current live URL when checked.

For troubleshooting, state the observed symptom first. Separate expected product behaviour from tenant-specific cause hypotheses. Do not claim a suspected root cause is proven without evidence.

If the target quarterly release, subscription, tenant setup, or supporting passage is unknown, say it is not established by the currently indexed sources. Revisit previous conclusions when newly ingested Oracle guidance changes the evidence.
